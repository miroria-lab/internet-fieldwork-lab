# Internet Fieldwork Lab

Small web experiments exploring unexpected needs, cultures and curiosities around the world.

## Lab Charter / 研究所憲章

Internet Fieldwork Lab exists to discover unexpected value on the internet through fast, small experiments.

1. **Speed > Perfection**
   考え切ってから出さない。60点で公開し、世界から反応をもらう。

2. **Human fieldwork ends after 25 minutes**
   面白くても25分で止める。深掘り候補はBacklogへ送る。

3. **Do not stay with one discovery**
   面白いアイデアを見つけても、その日のFieldworkでは育てない。

4. **Mass experimentation → Observation → Anomaly detection**
   当たりを予測するより、試行回数を増やす。

5. **Human 1 : AI 9**
   人間は好奇心・違和感・偶然を担当。
   AIは探索量・制作量・分析量を担当する。

6. **Exploration and mining are separate**
   鉱脈を見つけても、探索活動そのものをそこへ集中させない。

7. **Review the rules every 10 experiments**
   日々はルールに従う。
   改善や方針変更は節目でまとめて行う。

8. **Publish first. Build a project only after a signal appears**
   面白い発見も最初からプロジェクト化しない。
   最小形で公開し、反応を観測する。
   反応が出たものだけ、集客・改善・収益化を検討する。

## Core Loop

Explore → Discover → Build small → Publish → Observe → Detect anomalies → Dig deeper only when signals appear
